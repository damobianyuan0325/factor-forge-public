# Security Policy

## Scope

This repository is research-only and does not provide live trading execution.
Do not commit credentials, private datasets, notification identifiers, account
details, local runtime files, or production configuration.

## Reporting

Please report suspected credential exposure or security vulnerabilities through
GitHub's private vulnerability reporting feature. Do not include real secrets,
account numbers, or production logs in a public issue.

## Credential exposure

If a secret is committed, removing it from the latest revision is not enough.
Revoke or rotate it immediately, then purge it from repository history before
publishing any replacement.
